# Dynamic Pricing Sandbox

An educational browser-based simulation for learning dynamic pricing strategy. Master pricing across four industry scenarios: E-Commerce, Ride-Share, Hotel, and Event Tickets.

## Getting Started

```bash
npm install
npm start
```

## Build for Production

```bash
npm run build
```

The build output in `build/` is ready for static hosting (e.g., DigitalOcean App Platform).

## Technology Stack

- **React** — Functional components with hooks
- **Recharts** — Data visualizations
- **Google Fonts** — DM Sans, DM Mono
